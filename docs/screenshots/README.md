# GhostChat Screenshots Directory

Place your application screenshots in this directory with the following filenames:

| Filename | Purpose in README |
| :--- | :--- |
| `chat-main.png` | Main desktop chat window showing E2EE message bubbles & chat list |
| `mobile-view.png` | Screenshot of GhostChat running in a mobile browser (Chrome/Safari) |
| `walkie-talkie.png` | Screenshot of the Walkie-Talkie Push-to-Talk or Voice Note waveform |
| `video-call.png` | Screenshot of WebRTC Video Call or Screen Sharing session |
| `group-chat.png` | Screenshot of Group chat, group creator modal, or Group Info roster |
| `admin-dashboard.png` | Screenshot of the `/admin` administration fleet dashboard |
| `themes.png` | Screenshot showcasing the Hacker (green) or Executive (blue) theme |

*Note: Recommended format is PNG or JPG with high resolution.*
